# translit

Кириллица латиницей — алфавитом на выбор: библиотека для Node.js, команда в терминале и сайт-транслитератор.

```
$ npm start -- "Привет, жёлтый щенок"
Privet, zheltyi shchenok
```

Шаблон курса JavaRush «GitHub 2026». Код в `src/` — от курса, его не меняют; своё в проекте — алфавиты и настройка.

## Запуск

Нужен Node.js 24.12 или новее.

```
npm install
npm start -- Привет
npm start -- --list
npm start -- --alphabet iso9 "Жёлтый щенок"
npm test
```

## Свой алфавит

Алфавит по умолчанию — одна строка в `translit.config.json`:

```json
{
  "alphabet": "passport"
}
```

Готовые алфавиты — файлы данных в папке `alphabets/`:

- `passport` — паспортный, как в загранпаспорте;
- `iso9` — ISO 9 (1995), одна латинская буква на каждую кириллическую, с украинскими и белорусской;
- `ukrainian` — украинский, постановление Кабинета министров Украины 2010 года;
- `belarusian` — белорусский, инструкция 2023 года;
- `kazakh` — казахский, латиница 2021 года.

Новый алфавит — копия готового файла (например, `alphabets/passport.json`) под своим именем `alphabets/<имя>.json`: своё `name` — название, в `letters` поменять нужные буквы. Можно добавить `examples` — примеры «текст → латиница», тогда у алфавита будет свой тест. Необязательные поля готовых алфавитов: `wordStart` — буквы, которые в начале слова пишутся иначе, `wordStartAfter` — после каких букв это правило тоже действует, `pairs` — две буквы подряд со своей передачей. Буквы, которых в алфавите нет, переводятся паспортным, а которых нет и в нём, остаются как есть. `npm test` проверяет каждый файл в `alphabets/`.

## Сборка

- `npm run build` — пакет в `dist/`: JavaScript, типы и алфавиты. В архив `npm pack` идёт только `dist/`.
- `npm run build:site` — сайт-транслитератор в `site/`: страница, алфавиты и настройка.

`dist/` и `site/` — сборка, в репозиторий они не идут (`.gitignore`).
